# NILEST Workers' Annual Leave Management System
PHP 8 + MySQL + Bootstrap 5 | Case study: Nigerian Institute of Leather and Science Technology (NILEST), Samaru-Zaria

## Objectives implemented
1. Computerized staff, department and annual-leave records with search and filtering.
2. Staff login and electronic annual-leave applications with working-day calculations, entitlement/balance and overlap checks, and pending-request cancellation.
3. Administrative review, approval and rejection with remarks and balance enforcement.

## Setup (XAMPP / WAMP / Laragon)
1. Copy the project files into `htdocs/nilest_leave` (XAMPP) or `www/nilest_leave` (WAMP).
2. Start Apache and MySQL. Import `database.sql` using phpMyAdmin.
3. Configure database credentials in `config.php` if needed.
4. Visit http://localhost/nilest_leave/
